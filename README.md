## 🚀 About Me

I'm an AI/ML Engineer focused on building practical, production-oriented AI applications using Generative AI, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), multimodal AI, and Python backend engineering.

I enjoy turning complex problems into reliable AI-powered systems, from intelligent document processing and information retrieval to API-driven AI workflows and scalable backend services.

- 🔭 **Building:** LLM-powered applications, document intelligence, AI automation, and intelligent workflows.
- 🧠 **Exploring:** Agentic AI, multimodal reasoning, LLM fine-tuning, and scalable inference.
- 🤖 **AI Focus:** RAG pipelines, LLM orchestration, embeddings, vector search, OCR, and vision-language models.
- ⚙️ **Backend:** Python, FastAPI, REST APIs, asynchronous processing, Celery, and Redis.
- ☁️ **Cloud:** AWS, Azure, and Google Cloud technologies.
- 🌱 **Continuous Learning:** Model optimization, inference performance, AI system design, and MLOps.
- 💡 **Interests:** Applied AI, Generative AI, NLP, computer vision, and AI product engineering.
